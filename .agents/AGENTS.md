# Repository Synchronization Rule

Whenever a commit and push are performed in this workspace, ensure that the code is synchronized across the following three repositories:

1. https://github.com/VeralogixCatalyst/VeraLogix-SecureConnect-App.git
2. https://github.com/AN3S-CREATE/VeraLogix-SecureConnect-App.git
3. https://github.com/veralogix-group-innovation/VeraLogix-SecureConnect-App.git

This ensures all repositories have identical code. 

The local `origin` remote should be configured to push to all three repositories automatically.
