# Contributing to Veralogix

First off, thank you for considering contributing to Veralogix! It's people like you that make Veralogix such a powerful tool for the legal, compliance, and advocacy communities.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct:
- Use welcoming and inclusive language.
- Be respectful of differing viewpoints and experiences.
- Gracefully accept constructive criticism.

## How Can I Contribute?

### Reporting Bugs
This section guides you through submitting a bug report for Veralogix. Following these guidelines helps maintainers and the community understand your report, reproduce the behavior, and find related reports.
- Use the Bug Report issue template.
- Provide clear steps to reproduce the issue.
- Include screenshots if it is a UI bug.

### Suggesting Enhancements
This section guides you through submitting an enhancement suggestion, including completely new features and minor improvements to existing functionality.
- Use the Feature Request issue template.
- Explain *why* this enhancement would be useful to most users.

### Pull Requests
- Fill in the required Pull Request template.
- Do not include issue numbers in the PR title.
- Document any new code.
- Ensure all tests pass before requesting a review.

## Development Setup

1. Fork the repo and create your branch from `main`.
2. Run `npm install` to install dependencies.
3. If you've added code that should be tested, add tests.
4. If you've changed APIs or UI features, update the documentation.
5. Ensure your code lints via `npm run lint`.

Thank you for contributing!
