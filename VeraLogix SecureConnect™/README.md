# VeraLogix SecureConnect™

This is the official repository for the VeraLogix SecureConnect™ platform, built with Next.js, Firebase, and Genkit.

## Overview

VeraLogix SecureConnect™ is a high-security property management platform designed for Agents, Trustees, Residents, and Vendors. It provides a unified ecosystem for access control, incident management, financial oversight, and community services.

## Getting Started

To get started with development:

1.  Navigate to the project root: `cd "VeraLogix SecureConnect™"`
2.  Install dependencies: `npm install`
3.  Run the development server: `npm run dev`
4.  Open [http://localhost:9002](http://localhost:9002) in your browser.

## Key Technologies

- **Next.js 15 (App Router)** - Fast, server-first React framework.
- **Tailwind CSS & ShadCN UI** - Professional, brand-aligned design system.
- **Firebase** - Real-time database (Firestore) and secure Authentication.
- **Genkit** - Advanced AI integration for intelligent workflows.

## Project Structure

- `src/app/cmd`: Agent Command Center
- `src/app/tru`: Trustee/Owner Portal
- `src/app/ten`: Resident App
- `src/app/ven`: Vendor Portal
- `src/components`: Reusable UI components
- `src/ai`: Genkit AI flows and configurations
